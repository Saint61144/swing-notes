# Swing Notes

Swing Notes saves the text and dates from an open one-to-one Discord DM as
a local transcript. Choose your messages, the other person's messages, or both.
The combined export includes speaker labels.

## Install

Open `brave://extensions` or `chrome://extensions`, enable Developer mode, and
drag `Swing-Notes-2.0.5-Drop-In.zip` onto the page. For a source checkout, select
**Load unpacked** and choose the folder containing `manifest.json`.

## Export

Open a DM on Discord web, click Swing Notes in your toolbar, and choose an
export option. Keep the tab open while it loads older messages. The popup shows
a running count and lets you stop and save what it has found so far.

Swing Notes reads rendered messages after you start an export. The scan holds
messages in the current tab's memory and saves the transcript as a text file
through your browser. It does not send transcripts to a server.

Use the extension only with the required permissions. Discord's terms
restrict automated scraping without written consent. Get the other person's
permission before sharing a transcript.
